Einfachere Installation, verlässlichere Volltexte und mehr Transparenz beim Indexieren.

## Installation

- **Windows:** `Caitation-Setup-0.1.1.exe` unten herunterladen und ausführen. Kein Python, keine Adminrechte nötig; Caitation landet im Startmenü. Der Installer ist nicht signiert: Bei „Der Computer wurde durch Windows geschützt“ auf *Weitere Informationen → Trotzdem ausführen* klicken.
- **macOS/Linux:** *Source code (zip)* herunterladen, entpacken, `start.command` doppelklicken. Auch hier ist kein vorinstalliertes Python mehr nötig.
- **Zotero-Plugin:** `caitation-zotero-0.1.1.xpi` in Zotero über *Werkzeuge → Plugins → Zahnrad → Plugin aus Datei installieren…* Bereits installierte Plugins aktualisieren sich selbst.

**Update von 0.1.0:** Unter Windows den Installer in den bisherigen Caitation-Ordner installieren; Index und `.env` bleiben erhalten. Unter macOS/Linux den neuen Ordner entpacken und `data/` sowie `.env` aus dem alten Ordner hineinkopieren.

## Neu

- **Windows-Installer** mit Startmenü-Einträgen für Caitation und die Einstellungen (API-Key), optionalem Desktop-Symbol und sauberer Deinstallation.
- **Kein vorinstalliertes Python mehr nötig:** Die Startskripte richten Python 3.11 und alle Pakete selbst im Caitation-Ordner ein (ca. 2 Minuten).
- **Restzeit-Anzeige** beim Indexieren, gewichtet nach Dateigröße und hochgerechnet aus dem Tempo des eigenen Rechners.
- **Grafikkarte wird genutzt:** NVIDIA-Karten und Apple Silicon beschleunigen das Indexieren automatisch.
- **Abgebrochene Indexierung wird fortgesetzt**, wenn Caitation wieder startet.
- **Warnung bei neuen Zotero-Versionen**, deren Datenbankformat Caitation noch nicht kennt.
- Ein zweiter Start öffnet nur den Browser, statt einen zweiten Server zu starten.

## Verbessert

- **Sauberere Volltexte:** Trennzeichen und Steuerzeichen aus PDFs werden entfernt. Wörter, die am Zeilenende getrennt waren („Flem-ish“), findet die Stichwortsuche jetzt, und die Zitatprüfung erkennt sie.
- **PDFs mit kaputter Textebene** (Schriften ohne Zeichenzuordnung, die nur Zeichensalat liefern) werden erkannt und per OCR gelesen. Solche Paper waren bisher praktisch unauffindbar.
- **Server bleibt erreichbar:** Unter Windows konnte Caitation nach abgebrochenen Verbindungen (z.B. bei stark ausgelastetem Rechner) unbemerkt aufhören zu antworten. Behoben.
- Ein bestehender Index wird beim ersten Start **einmalig repariert**, ohne alles neu einzulesen. Das Bereinigen dauert je nach Bibliothek und Festplatte einige Minuten bis etwa eine halbe Stunde; Paper mit unlesbarer Textebene werden danach im Hintergrund per OCR neu gelesen, was bei langen Büchern Stunden dauern kann. Caitation ist währenddessen nutzbar.
