Erste Version von Caitation: semantische Suche, Fragen und Belegprüfung für die eigene Zotero-Bibliothek. Alles läuft lokal; nur der Frage- und Beleg-Modus schickt Ausschnitte an die Claude-API (eigener API-Key nötig).

## Installation

1. Repository herunterladen (grüner Knopf *Code → Download ZIP*) und entpacken.
2. `start.bat` (Windows) bzw. `start.command` (macOS/Linux) doppelklicken. Beim ersten Start wird alles eingerichtet; danach öffnet sich Caitation im Browser.
3. Für den Frage- und Beleg-Modus den Anthropic-API-Key in die Datei `.env` eintragen.
4. Optional das Zotero-Plugin installieren: `caitation-zotero-0.1.0.xpi` unten herunterladen, in Zotero *Werkzeuge → Plugins → Zahnrad → Plugin aus Datei installieren…*

Voraussetzungen: Python 3.11, Zotero 8 oder 9, ca. 3 GB Arbeitsspeicher. Die erste Indexierung macht die Bibliothek nach wenigen Minuten durchsuchbar (Titel, Abstracts, Highlights); die Volltexte folgen im Hintergrund und können bei großen Bibliotheken Stunden dauern.

## Funktionen

- **Suche** über Volltexte (PDF inkl. OCR, gespeicherte Webseiten, EPUB), Metadaten und deine Highlights, mit präzisem Nachsortieren
- **Fragen** an die Bibliothek mit APA-Zitaten und Seitenangaben
- **Beleg prüfen**: welche Quellen eine Behauptung stützen oder ihr widersprechen
- **Zitatprüfung**: jedes wörtliche Zitat wird gegen den Quelltext geprüft (✓ belegt, ≈ abweichend, ⇄ übersetzt, ✗ nicht gefunden), inklusive Seitenzahl
- **Zotero-Plugin**: ähnliche Paper in der Seitenleiste, Suche und Belegprüfung aus markiertem Text im PDF-Reader
- Dashboard mit Themenkarte, Dubletten-Übersicht, BibTeX-Export, Gruppenbibliotheken, verlinkte Dateien

Rückmeldungen und Fehlerberichte gern als Issue. Bei Problemen hilft die Datei `data/caitation.log`.
